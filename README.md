  ## 🏆 Featured Project: BuhayLink
  *A modern, cross-platform mobile development stack designed for scalability.*

  > **Architecture:** Feature-First / Clean Architecture  
  > **State Management:** Provider (Global Auth) & Ephemeral State

  **🏗️ Architectural Decisions (SOLID Principles)** <br>
  *This project strictly adheres to SOLID Principles to ensure code maintainability.*

  * **Feature-First Structure:** Codebase organized by domain features (Auth, Job Posting, Profile) rather than technical layers, ensuring easy scalability.
  * **Single Responsibility:** UI rendering is strictly decoupled from business logic. `DashboardPage` handles navigation, delegating data fetching to `HomeFeedPage`.
  * **Repository Pattern:** UI never communicates directly with Firestore. All data fetching is abstracted into Repositories.

  **🚀 Key Features Implemented**
  * **Role-Based Dashboards:** Distinct workflows for Employers vs. Workers.
  * **Smart Filtering:** Client-side filtering for "Urgent", "High Pay", and "Nearby" jobs (Geocoding).
  * **Optimized Performance:** `cacheExtent` and `RepaintBoundaries` implemented for smooth scrolling.
